# Толмач — офлайн-переводчик RU ⇄ EN для Android

Двухпанельный переводчик: сверху **Russian**, снизу **English**. Набираете текст в любой
половине — во второй сразу появляется перевод.

* Русский ⇄ английский, в обе стороны.
* **Совсем без интернета**: приложение не запрашивает разрешение на сеть, модели лежат в APK.
* Полностью свободный стек: OPUS-MT (CC-BY 4.0) + ONNX Runtime (MIT) + AndroidX/Material.
* Никаких сервисов Google, аккаунтов, ключей API и аналитики. Работает на AOSP.
* Android 8.0 … Android 16 (`minSdk 26`, `targetSdk 35`).

## Возможности

| Действие | Результат |
|---|---|
| Тап по надписи `Russian` / `English` | Обе половины очищаются, языки меняются местами |
| Ввод текста | Перевод во второй половине в реальном времени |
| Кнопка вставки (документ со стрелкой) | Вставляет текст из буфера обмена в эту половину |
| Кнопка копирования (два листа) | Копирует **весь** текст этой половины в буфер обмена |
| Долгое нажатие в поле | Системное меню: вставить, выделить, скопировать **часть** текста |
| Кнопка «ухо» | Читает текст этой половины системным голосовым движком; повторное нажатие останавливает |
| `A−` / `A+` | Размер шрифта 12…32 sp, запоминается |
| Кнопка «контраст» | Светлая ⇄ тёмная тема, запоминается |
| Крошки `Толмач › История переводов › Справка` | Переход к истории и справке |

### История переводов

50 последних переводов с датой и временем (день, часы, минуты, секунды). Нажатие на запись
возвращает на экран перевода и подставляет исходный текст и перевод в те же половины.

### Справка

Пункт «Справка» открывает `app/src/main/res/raw/help.md` — описание всех возможностей,
лицензий и работы офлайн.

### Заставка и иконка

Заставка — древнерусский старец-летописец с гусиным пером, иконка — гусиное перо на
рукописном свитке.

## Движок перевода

* **Модель:** OPUS-MT `opus-mt-ru-en` и `opus-mt-en-ru` (Helsinki-NLP), лицензия **CC-BY 4.0**.
* **Формат:** ONNX, int8-квантование (`encoder.onnx` ≈ 49 МБ, `decoder.onnx` ≈ 56 МБ на направление).
* **Инференс:** ONNX Runtime для Android (`com.microsoft.onnxruntime:onnxruntime-android`), лицензия MIT.
* **Токенизатор:** SentencePiece Unigram, реализован в `opus/OpusTokenizer.kt`; словарь лежит
  в компактном двоичном файле `tokenizer.bin` (1,2 МБ) — без JSON-парсинга на телефоне.
* **Декодирование:** жадное, без кэша past-состояний — проще и предсказуемее по памяти.

Модели вшиты в `app/src/main/assets/models/{ru-en,en-ru}/` и при первом обращении
распаковываются во внутреннюю папку приложения. Сеть не используется ни на одном шаге,
разрешение `INTERNET` в манифесте отсутствует.

В памяти держится только одно направление: при смене языка предыдущая модель закрывается,
чтобы не ловить OOM на телефонах с 1–2 ГБ ОЗУ.

## Проверка корректности

Токенизатор и инференс проверяются JVM-тестом против эталонных ответов, снятых с той же
модели в Python (`transformers`/`onnxruntime`):

```bash
./gradlew testDebugUnitTest
```

Тест сверяет id токенов и готовые переводы для набора фраз в обе стороны.

## Сборка

### Android Studio
1. `File → Open` → папка проекта.
2. Дождаться синхронизации Gradle (JDK 17, Android SDK 35).
3. `Run ▶`.

### Командная строка
```bash
./gradlew assembleDebug     # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
```

APK получается ~227 МБ: почти весь объём — модели перевода и библиотеки ONNX Runtime для
четырёх архитектур. После установки приложение распаковывает модели (~210 МБ) во внутреннюю
память, поэтому нужно ~250 МБ свободного места.

### Подпись релиза

Ключ и пароли — в `keystore/tolmach-release.jks` и `keystore.properties`; оба файла
в `.gitignore`. Без `keystore.properties` релиз подписывается отладочным ключом.
Сохраните keystore: без него нельзя выпустить обновление поверх установленной версии.

## Установка

```bash
adb install -r app-release.apk
```

## Структура

```
app/src/main/java/ru/tolmach/translator/
  SplashActivity.kt      заставка с летописцем
  MainActivity.kt        две половины, ввод, вставка/копирование, озвучка, тема, шрифт
  HistoryActivity.kt     список 50 последних переводов
  HistoryAdapter.kt      элементы списка истории
  HelpActivity.kt        экран справки
  BreadcrumbsView.kt     меню «хлебные крошки»
  HistoryStore.kt        хранение истории в history.json
  OpusEngine.kt          движок: распаковка моделей из APK, кэш одного направления
  TranslationEngine.kt   интерфейс движка и языки
  opus/OpusTokenizer.kt  SentencePiece Unigram + двоичный словарь
  opus/OpusModel.kt      ONNX Runtime: энкодер и жадное декодирование
  Prefs.kt               тема и размер шрифта
  TolmachApp.kt          Application: движок, история, тема
app/src/test/java/…/opus/OpusTranslationTest.kt  сверка с эталоном на JVM
app/src/main/assets/models/                     модели OPUS-MT в APK
app/src/main/res/raw/help.md                    справочный файл
```
