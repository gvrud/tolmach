# Толмач — офлайн-переводчик RU ⇄ EN для Android

Двухпанельный переводчик: сверху **Russian**, снизу **English**. Набираете текст в любой
половине — во второй сразу появляется перевод.

* Русский ⇄ английский, в обе стороны.
* Перевод целиком на устройстве — без серверов, аккаунтов и ключей API.
* Бесплатные компоненты: Kotlin, AndroidX, Material Components, ML Kit Translation (on-device),
  системный синтез речи Android.
* Android 8.0 … Android 16 (`minSdk 26`, `targetSdk 35`).
* Без рекламы, аналитики и подписок.

## Возможности

| Действие | Результат |
|---|---|
| Тап по надписи `Russian` / `English` | Обе половины очищаются, языки меняются местами |
| Ввод текста | Перевод во второй половине в реальном времени (~0,25 с задержки) |
| Кнопка вставки (документ со стрелкой) | Вставляет текст из буфера обмена в эту половину |
| Кнопка копирования (два листа) | Копирует **весь** текст этой половины в буфер обмена |
| Долгое нажатие в поле | Системное меню: вставить, выделить, скопировать **часть** текста |
| Кнопка «ухо» | Читает текст этой половины системным голосовым движком; повторное нажатие останавливает |
| `A−` / `A+` | Размер шрифта 12…32 sp, запоминается |
| Кнопка «контраст» | Светлая ⇄ тёмная тема для обеих половин, запоминается |
| Крошки `Толмач › История переводов › Справка` | Переход к истории и к справке |

### История переводов

50 последних переводов с датой и временем (день, часы, минуты, секунды). Нажатие на запись
возвращает на экран перевода и подставляет исходный текст и перевод в те же половины,
направление перевода восстанавливается. Пока фраза дописывается, последняя запись
обновляется на месте, поэтому история не забивается обрывками слов.

### Справка

Пункт «Справка» открывает справочный файл `app/src/main/res/raw/help.md` — описание всех
возможностей приложения прямо внутри программы.

### Заставка и иконка

Заставка — древнерусский старец-летописец с гусиным пером, иконка — гусиное перо на
рукописном свитке. Исходные изображения лежат в ресурсах: `drawable-nodpi/splash_chronicler.jpg`
и `mipmap-*/ic_launcher_fg.png`.

## Работа без интернета

Перевод выполняет модель на телефоне (ML Kit Translation). Модели RU→EN и EN→RU
(≈30 МБ на направление) скачиваются **один раз** при первом запуске — для этого нужна сеть.
Дальше приложение работает полностью офлайн. Без сети при первом запуске приложение
открывается и принимает текст, но перевода не будет, пока модель не скачана.

## Сборка

### Android Studio
1. `File → Open` → папка проекта.
2. Дождаться синхронизации Gradle (JDK 17, Android SDK 35).
3. `Run ▶`.

### Командная строка
```bash
./gradlew assembleDebug     # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
```
Windows: `gradlew.bat assembleDebug`.

### Подпись релиза
Ключ и пароли лежат в `keystore/tolmach-release.jks` и `keystore.properties`; оба файла
в `.gitignore` и в репозиторий не попадают. Без `keystore.properties` релиз подписывается
отладочным ключом. Сохраните keystore: без него нельзя выпустить обновление поверх
установленной версии.

## Установка

```bash
adb install -r app-release.apk
```
Или скопировать APK на телефон и открыть (нужно разрешить установку из неизвестных источников).

APK универсальный (все ABI), поэтому весит ~65 МБ — почти всё это нативные библиотеки ML Kit.
Для Google Play лучше собирать AAB: `./gradlew bundleRelease`.

## Структура

```
app/src/main/java/ru/tolmach/translator/
  SplashActivity.kt      заставка с летописцем
  MainActivity.kt        две половины, ввод, вставка/копирование, озвучка, тема, шрифт
  HistoryActivity.kt     список 50 последних переводов
  HistoryAdapter.kt      элементы списка истории
  HelpActivity.kt        экран справки
  BreadcrumbsView.kt     меню «хлебные крошки»
  HistoryStore.kt        хранение истории в history.json
  TranslationEngine.kt   интерфейс движка + офлайн-реализация на ML Kit
  Prefs.kt               тема и размер шрифта
  TolmachApp.kt          Application: движок, история, тема
app/src/main/res/raw/help.md               справочный файл
app/src/main/res/layout/activity_main.xml  две равные половины экрана
```

Движок вынесен за интерфейс `TranslationEngine`: чтобы перейти на другую бесплатную
офлайн-модель (например, OPUS-MT в ONNX Runtime), достаточно добавить реализацию и
подменить её в `TolmachApp.engine`.
